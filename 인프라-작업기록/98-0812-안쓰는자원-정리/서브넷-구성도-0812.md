## 3. ⬜`catchap-gpu-2a` (10.0.5.0/24) 가 비었습니다

옛 GPU 서버(`10.0.5.57`)를 0812 에 지웠고, **STT 는 GPU 노드풀로 옮겨졌습니다.**

### 안 쓴다는 근거 — 세 가지를 따로 확인했습니다

```
① 포트          3개 전부 배관(dhcp 2 · router 1) · 서버 0 · 로드밸런서 0
② 클러스터 설정  catchap-cluster-prod 의 서브넷 = ★core-2a · core-2b ★둘뿐
                → gpu-2a 는 클러스터가 ★쓸 수 있는 목록에 아예 없다
③ 노드풀        catchap-nodpol-prod(m2a.xlarge) · catchap-gpu-prod(gn1i.4xlarge)
                둘 다 노드 2대 · 영역 2-a+2-b · 실제 노드는 10.0.2.x · 10.0.6.x
                → GPU 노드도 ★core 서브넷에 뜬다
```

★**「지금 비었다」만으로는 부족합니다.** 나중에 노드가 늘어날 때 이 서브넷을 쓰게
되어 있으면 지우면 안 되기 때문에, **②번(클러스터가 쓸 수 있는 서브넷 목록)** 을
확인한 것이 결정적이었습니다.

⬜**지울지는 사장님 판단입니다.** 비어 있어도 비용이 들지는 않습니다.
