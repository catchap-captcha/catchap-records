## 3. ✅Secrets Manager — 금고와 앱이 정확히 일치

앱이 참조하는 이름을 ConfigMap 에서 뽑아 금고 목록과 대조했습니다.

```

backend-migrate  1건   stt-worker   1건   (겹치는 것 제외 ★21개)
금고 실제                                  ★21건
→ 고아 시크릿 0개
```

⚠️**콘솔 목록 2쪽이 `0 – 0 / 0` 으로 비어 나옵니다** — 0808 에 겪은 「목록이 잘려 나오는」
함정과 같은 모양입니다. 21번째(`catchap-portone-keys`)의 존재는 **기능으로 증명**했습니다:
백엔드는 필수 변수 관문이 켜져 있어 시크릿 하나라도 못 읽으면 기동하지 못하는데,
지금 정상 기동 중입니다.
