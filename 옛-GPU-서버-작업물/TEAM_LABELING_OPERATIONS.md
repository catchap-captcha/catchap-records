## 4. 팀 사용 방법

각 팀원은 자기 PC에서 SSH 터널을 열고 브라우저로 접속합니다. 서버의 8000 포트를 인터넷 주소로 직접 열지 말고 터널 사용을 권장합니다.

Windows PowerShell 예시:

```powershell
ssh -i "C:\키경로\개인키.pem" -N -L 18000:127.0.0.1:8000 ms@61.109.239.231
```

`my`, `sw`, `jy`는 명령의 Linux 사용자 이름을 자기 이름으로 바꿉니다. 로컬 18000 포트가 사용 중이면 18001 등으로 바꿉니다.

macOS 예시:

```bash
chmod 600 ~/키경로/개인키.pem
ssh -i ~/키경로/개인키.pem -N -L 18000:127.0.0.1:8000 ms@61.109.239.231
```

터널을 켠 상태에서 브라우저로 아래 주소를 엽니다.

```text
http://127.0.0.1:18000/admin
```

웹 계정과 Linux SSH 계정은 별개입니다.

1. 웹 아이디 `ms`, `my`, `sw`, `jy` 중 자기 계정으로 로그인
2. 최초 로그인 시 임시 비밀번호를 12자 이상의 새 비밀번호로 변경
3. `다음 작업 가져오기` 또는 목록에서 원하는 작업 선택
4. bbox, 라벨, 역할과 한국어 지시문 수정
5. 임시 저장하거나 `직접 승인 및 배포`, 또는 `제외` 선택

공개 회원가입 화면은 없으며 추가 계정은 관리자 작업으로만 생성합니다.

## 5. 동시 작업 보호

- 작업 잠금: 한 작업은 한 명만 편집
- 잠금 시간: 30분
- 작업 중 하트비트: 5분 간격으로 잠금 연장
- 계정당 동시에 한 작업만 잠금
- 30초 자동 저장
- 버전 충돌 방지: 같은 버전을 동시에 저장하면 한 요청만 성공, 다른 요청은 HTTP 409
- 모든 임시 저장, 자동 저장, 승인, 제외를 `label_revisions`에 추가형 이력으로 보존
- 승인 배포를 `label_publish_jobs`로 기록하고 중복 실행 차단
- 매니페스트는 임시 파일, `fsync`, 원자적 교체 방식으로 생성
- 객체를 화면에서 제거해도 과거 CAPTCHA 외래키를 위해 DB 행은 `invalid`로 보존
- 관리자 세션 12시간, HttpOnly/SameSite 쿠키
- 로그인 실패는 감사 이벤트로 기록하며 동일 IP 15분 20회 제한
