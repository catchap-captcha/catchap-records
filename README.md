# catchap-records — 작업 기록 보존소

★**이 저장소는 「코드」가 아니라 「기록」을 둡니다.** 인프라 작업 이력, 콘솔 캡처,
문서, 화면 캡처처럼 **잃어버리면 다시 못 만드는 것**을 여기 둡니다.

⚠️**아직 비어 있습니다(2026-08-10 기준).** 자리만 잡아 둔 상태입니다.

---

## 왜 만들었나

```
인프라-캡처   1,033개 · 320.9 MB   ← ★깃허브 어디에도 없었습니다
  30-작업이력    537개 · 121.0 MB    작업 기록 84건
  20-카카오문서    43개 ·  74.1 MB
  40-깃허브캡처   119개 ·  34.9 MB
  .md 문서       106개 ·   1.8 MB   ← 글은 여기 다 있습니다

catchap-infra 저장소   115개 (쿠버네티스 매니페스트뿐)
```

★**작업하던 컴퓨터가 고장 나면 지금까지의 인프라 기록이 전부 사라지는 상태**였습니다.
코드는 저장소에 있는데 **「왜 그렇게 했는지」가 한 곳에만** 있었습니다.

⚠️**오브젝트 스토리지는 보존처가 아닙니다.** 언젠가 반납할 자원이라, 거기 둔 것은
반납과 함께 사라집니다. 그래서 깃허브로 옮깁니다.
